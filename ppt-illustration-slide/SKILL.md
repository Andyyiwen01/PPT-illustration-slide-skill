# PPT Illustration Slide

将用户素材（图片 + 文字，或纯文字）整理为一页带手绘抽象插画的 PPT 横版页面。

## 输出规格

- 画幅：16:9 横版，宽 1920 × 高 1080 像素
- 插画风格：高智感手绘汇报风——细腻手绘线稿 + 淡暖彩填充，线条纤细有松弛感，像高级手账/咨询笔记本内页，不要粗黑描边卡通
- 字体：全页不超过 2 种字体；字体颜色不超过 2 种（深暖棕 + 香槟金点缀）
- 最小字号：正文不小于 10pt（1920×1080 画布下约对应 28px 以上）
- 背景：奶油米白底色（#F5EFE3 感），带极轻微纸纹理，保持干净暖白留白
- 配色：整体锁定香槟/米色/奶油暖色系（奶油米白 + 香槟金 + 暖深棕），不要藏青、酒红、亮蓝等高饱和冷色撞色

## 工作流程

### Step 1: 分析输入

#### 情况 A — 用户上传了图片

先 Read 图片，提取以下信息：
1. **场景类型**：这是室内/室外？工作场景/生活场景/产品特写？
2. **关键物品**：画面中有哪些核心物体？（如桌子、沙发、投影仪、元器件）
3. **关键人物**：有人吗？几人？在做什么动作？
4. **主要色彩**：主色调是什么？（冷色/暖色/中性色）
5. **方位关系**：核心物体之间的位置关系（如"桌子在沙发右侧，投影仪在桌子正前方"）

#### 情况 B — 用户只上传了文字描述

按以下逻辑拆解用户描述：
1. **概括对象**：用户描述的是一个**场景**？一个**物品**？一个**人物**？一个**群像**？还是一个**概念/流程**？用一句话给出总体概括。
2. **方位总结**：描述中提到的元素之间的空间位置关系。如果原文没有明确方位，根据常识和描述合理推断。
3. **元素清单**：列出画面中应出现的主要元素（3–6 个为宜），每个元素一句话说明其作用或特征。

### Step 2: 决定插画位置

根据内容类型选择布局：

| 内容类型 | 布局方式 | 理由 |
|---|---|---|
| 元器件 / 产品解剖 / 结构说明 | 插画居中，文字标注分布在四周引线 | 需要逐一讲解每个部件，居中便于引线指向 |
| 会议室 / 展厅 / 空间场景 | 插画占左侧 55–60%，文字要点在右侧 40–45% | 场景整体感强，文字做要点提炼即可 |
| 人物 / 群像 / 肖像 | 插画偏左或居中偏左，文字在右侧 | 突出人物形象，文字做背景介绍 |
| 物品 / 产品外观 | 插画居中偏左，文字在右侧分点 | 产品展示为主，文字讲特点 |
| 流程 / 关系图 | 插画占上半或居中，文字在下方分点 | 抽象关系需要图示辅助 |

### Step 3: 整理文字内容

把用户原始描述重组为**分点要点**：
- 标题：一句话概括，不超过 20 字
- 正文：3–5 个要点，每点一行，用 • 或数字编号
- 要点之间有逻辑顺序（从整体到局部 / 从左到右 / 从上到下）
- 保留用户原文中的关键术语和专有名词，不要凭空添加用户没提到的事实

### Step 4: 生成最终 PPT 图片

调用 `image_gen` 工具生成最终页面。prompt 中必须明确包含：

1. **画幅**：16:9 横版 PPT 页面，宽屏演示文稿风格
2. **插画内容**：手绘风格抽象插画，描述画面中应出现的元素和方位关系
3. **排版布局**：插画位置 + 文字区域位置（参考 Step 2 的布局表）
4. **文字内容**：标题 + 各要点，用中文引号包裹
5. **样式约束**：高智感手绘汇报风，细腻手绘线稿+淡暖彩填充，配色锁定香槟/米色/奶油暖色系（奶油米白底+香槟金+暖深棕），字体清晰可读，背景奶油米白带极轻纸纹理

#### Prompt 模板

```
一张 16:9 横版 PPT 演示页面，奶油米白底色（#F5EFE3 感），带极轻微纸纹理，暖白留白。

页面布局：[根据 Step 2 填写，如"左侧约 55% 区域为手绘插画，右侧约 45% 区域为文字内容"]

手绘插画部分：[描述插画内容，包括主体、关键元素、方位关系、风格——如"细腻手绘线稿+淡暖彩填充风格的现代会议室场景：长形会议桌居中摆放，周围环绕 8 把办公椅，前方墙面挂着投影仪幕布，窗边有绿植点缀。线条纤细有手绘松弛感，配色以浅木色、香槟金和暖棕为主，无高饱和色、无粗黑描边。"]

文字部分：
- 页面顶部/右侧大标题："[标题文字]"，优雅衬线体，深暖棕色
- 正文要点（分点排列，字号适中，清晰可读，深暖棕色无衬线体）：
  • "[要点 1]"
  • "[要点 2]"
  • "[要点 3]"

整体风格：高智感手绘汇报风，香槟米色系，像高级咨询手账内页，文字排版整齐，留白充足，克制优雅，不拥挤。所有文字使用简体中文，不要出现乱码或伪文字。
```

## 注意事项

- 如果用户上传了图片，插画内容必须忠实于原图的关键物品和方位关系，不要凭空添加原图没有的东西。
- 如果用户只有文字，插画可以做适当的艺术抽象化，但核心元素和方位必须符合描述。
- 文字内容不要照抄用户大段原文，要提炼成要点。
- 生成后检查：文字是否清晰可读、插画是否与内容匹配、布局是否平衡。
