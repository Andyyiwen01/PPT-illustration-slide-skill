# PPT Illustration Slide（PPT 插画讲解页 Skill）

> 将用户上传的图片和/或文字描述，整理成一页**带手绘风格抽象插画**的 **16:9 PPT 横版页面**。高智感手绘汇报风，香槟/米色/奶油暖色调，文字分点排布在插画周围。

适用于 AI 助手（如豆包等支持 Skill 机制的智能体）的图文讲解页生成任务。输入可以是**单张图片 + 一段文字**或**纯文字描述**，输出直接是一张 PPT 页面图片。

---

## ✨ 核心特点

| 能力 | 说明 |
|---|---|
| **双模式输入** | 有图时 Read 原图提取场景/物品/人物/色彩/方位；纯文字时概括对象 + 推断方位 + 列元素清单 |
| **内容驱动布局** | 按内容类型选布局：结构说明→居中引线标注；空间场景→左图右文；人物→左图右介绍；流程→上图下文 |
| **要点化重组** | 原始描述提炼为 ≤20 字标题 + 3–5 个分点要点，保留原文关键术语，不凭空添加事实 |
| **高智感手绘风** | 细腻手绘线稿 + 淡暖彩填充，奶油米白底 + 香槟金 + 暖深棕，克制优雅 |

> ⚠️ 注意：产物是**一张页面图片**（非 .pptx 文件）。若用户只要文字排版不要插画，不要使用本 Skill。

## 🚀 安装

将整个 `ppt-illustration-slide` 文件夹放入你的 Skill 根目录即可：

```bash
cp -r ppt-illustration-slide ~/.doubao/agent_mode/workspace/.user_skills/
```

安装后重启会话，当用户请求「把这段描述做成一页 PPT」「根据这张图配个插画做 PPT」时，Skill 会自动匹配生效。

## 🧭 使用流程

1. **分析输入**：
   - 有图 → Read 原图，提取场景类型 / 关键物品 / 关键人物 / 主要色彩 / 方位关系
   - 纯文字 → 概括对象（场景/物品/人物/群像/概念流程）+ 方位总结 + 元素清单（3–6 个）
2. **决定布局**：按内容类型查布局表（结构说明→居中引线 / 空间场景→左 55–60% / 人物→偏左 / 物品→居中偏左 / 流程→上图下文）。
3. **整理文字**：≤20 字标题 + 3–5 个分点要点，逻辑有序，保留专有名词。
4. **生成图片**：按 prompt 模板调用 `image_gen`，明确画幅、插画内容、排版布局、文字内容、样式约束。

## 🎨 输出规格

- **画幅**：16:9 横版，**1920 × 1080 px**（注意：与同系列其他 Skill 的 2048×1152 不同）
- **插画风格**：细腻手绘线稿 + 淡暖彩填充，线条纤细有松弛感，不要粗黑描边卡通
- **字体**：全页 ≤ 2 种；字体颜色 ≤ 2 种（深暖棕 + 香槟金点缀）；正文 ≥ 10pt（约 28px）
- **背景**：奶油米白（#F5EFE3 感）+ 极轻微纸纹理，干净暖白留白
- **配色**：锁定香槟/米色/奶油暖色系，不要藏青、酒红、亮蓝等高饱和冷色撞色

## 📋 布局速查

| 内容类型 | 布局方式 |
|---|---|
| 元器件 / 产品解剖 / 结构说明 | 插画居中，文字标注四周引线 |
| 会议室 / 展厅 / 空间场景 | 插画占左侧 55–60%，文字在右侧 40–45% |
| 人物 / 群像 / 肖像 | 插画偏左或居中偏左，文字在右侧 |
| 物品 / 产品外观 | 插画居中偏左，文字在右侧分点 |
| 流程 / 关系图 | 插画占上半或居中，文字在下方分点 |

## ❓ 常见问题

**Q：用户上传的图片和文字冲突时听谁的？**
插画必须忠实于原图的关键物品和方位关系，不凭空添加原图没有的东西；文字要点提炼自用户描述，不照抄大段原文。

**Q：纯文字输入时插画可以自由发挥吗？**
可以适当艺术抽象化，但核心元素和方位必须符合描述，不能跑偏。

**Q：为什么强调字体颜色 ≤ 2 种？**
深暖棕为主 + 香槟金点缀，才能维持高级手账的克制感；颜色一多就廉价。
